🧬 什麼是 Space？

每個 Space 都是一個程式碼儲存庫。透過 README.md 檔案開頭的設定區塊，就能設定執行環境、開發套件、硬體與標題。

目前的 Space 就是使用這種設定方式。變更 sdk:，就能調整 Hugging Face 建置與提供服務的應用程式類型。

🛠️ 建立 Space 的三種方式

選擇適合應用程式的開發套件。

🐍

Gradio

以 Python 開發，是最常見的 Space 類型。只需幾行 gr.Interface(...)， 就能建立操作介面並自動產生 REST/MCP API，也支援 ZeroGPU。

需要運算資源
📦

Docker

自由選擇容器與技術組合，例如 Streamlit、FastAPI、Node、Rust。 透過 Dockerfile 完整掌控環境，適合超出 Gradio 支援範圍的需求。

需要運算資源
⚡

靜態網頁

使用 HTML/JS，或建置完成的 React/Vue/Svelte 應用程式，搭配 WebGPU/WASM 在瀏覽器中執行機器學習。 所有人皆可免費使用，目前的網頁就是一個範例。

免費 · 不需要伺服器硬體

⚙️ 硬體方案

靜態網頁不需要伺服器運算資源。Gradio 與 Docker 需要運算資源，通常需要付費方案； 免費帳號則有 ZeroGPU 這個例外選項。

方案說明免費帳號可用？
靜態網頁不需要伺服器，由瀏覽器執行✓ 不限數量
ZeroGPU依請求提供 A10G 等級的 GPU 運算資源✓ 最多 2 個*
cpu-basic2 個虛擬 CPU 核心 / 16 GB 記憶體，持續執行✗ 需要付費方案
專用 GPUT4 至 H200，按小時計費✗ 需要付費方案

✨ Space 的應用功能

🔌 自動產生 API 與 MCP

Gradio Space 也能提供 REST API 與 MCP 伺服器，讓函式成為可呼叫的工具。

🔐 機密與環境變數

建立 Space 時或之後，都能以機密設定保存 API 金鑰， 並以環境變數提供公開設定。

💾 儲存桶

Space 本身不保留狀態，但可以將儲存桶掛載至 /data，長期保存資料。

🧩 嵌入其他網頁

每個 Space 都能透過 iframe 嵌入網頁，Gradio Space 也提供 JavaScript 與 Python 用戶端。

🌐 模型推論服務供應商

串接 Cerebras、Together、Fireworks 等服務， 不需要本機顯示記憶體也能執行大型模型。

👥 社群互動

支援按讚、討論與複製，任何人都能一鍵建立 你的 Space 副本。
